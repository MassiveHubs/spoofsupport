# 🤵 SpoofVPN Support Bot

Телеграм-бот поддержки с режимом топиков (Forum Topics), системой FAQ и управлением тикетами.

---

## ✨ Возможности

- 📩 **Тикет-система** — каждое обращение пользователя создаёт отдельный топик в группе администраторов
- 🔒 **Клейм тикетов** — модератор берёт тикет "в работу" командой `/claim`, после чего только он может отвечать в нём
- 👥 **Добавление коллег** — `/add` позволяет добавить другого модератора в заклеймленный тикет; если username не найден — показывается inline-список участников группы
- 🔇 **Тихий режим** — `/silent` позволяет писать заметки внутри топика, не пересылая их пользователю
- ❓ **FAQ** — пользователи могут просматривать часто задаваемые вопросы прямо в боте
- 🛠 **Редактирование FAQ без перезагрузки** — изменения в `faq.json` применяются мгновенно
- 📢 **Рассылка** — администратор может отправить сообщение всем пользователям бота
- 📊 **Статистика** — количество тикетов, активных обращений и пользователей
- 🔁 **Пересылка медиа** — бот пересылает текст, фото, видео, документы, голосовые, стикеры и анимации в обе стороны

## ⚙️ Установка

### Требования

- Python 3.11+
- Telegram-бот (создать через [@BotFather](https://t.me/BotFather))
- Группа с включёнными топиками (Topics / Forum mode)

### 1. Клонировать репозиторий

```bash
git clone https://github.com/MassiveHubs/spoofsupport.git
cd spoofsupport
```

### 2. Создать виртуальное окружение и установить зависимости

```bash
python -m venv venv
# Windows
venv\Scripts\activate
# Linux / macOS
source venv/bin/activate

pip install -r requirements.txt
```

### 3. Настроить `.env`

Скопируйте пример и заполните переменные:

```bash
cp .env.example .env
```

```env
BOT_TOKEN=ваш_токен_бота
GROUP_ID=-100xxxxxxxxxx
ADMIN_IDS=123456789,987654321
```

| Переменная  | Описание |
|-------------|----------|
| `BOT_TOKEN` | Токен бота от @BotFather |
| `GROUP_ID`  | ID группы с топиками (отрицательное число, начинается с `-100`) |
| `ADMIN_IDS` | Список ID администраторов через запятую |

### 4. Запустить бота

```bash
python main.py
```

## 🐳 Запуск через Docker

```bash
docker compose up -d --build
```

`support.db` и `faq.json` монтируются с хоста — данные сохраняются при пересборке.

## 📋 Команды

### Пользователь (в личке с ботом)

| Команда | Описание |
|---------|----------|
| `/start` | Главное меню |
| `/faq` | Просмотр FAQ |

### Модератор (в топике тикета)

| Команда | Описание |
|---------|----------|
| `/claim` | Взять тикет в работу (только вы отвечаете) |
| `/unclaim` | Снять клейм с тикета |
| `/add @username` | Добавить коллегу в заклеймленный тикет |
| `/add` | Выбрать коллегу из inline-списка участников группы |
| `/silent` | Переключить тихий режим (заметки без пересылки) |
| `/close` | Закрыть тикет |
| `/info` | Информация о текущем тикете |

### Администратор (в личке с ботом)

| Команда | Описание |
|---------|----------|
| `/start` | Меню с кнопками "Рассылка" и "Статистика" |

## 📝 Редактирование FAQ

Файл `faq.json` содержит массив объектов:

```json
[
  {
    "question": "Как подключиться к VPN?",
    "answer": "Скачайте приложение и введите ключ из личного кабинета."
  },
  {
    "question": "Какие протоколы поддерживаются?",
    "answer": "WireGuard, VLESS, Shadowsocks."
  }
]
```

Изменения применяются **без перезапуска бота**.

## 🛡 Как работает система клейма

1. Пользователь пишет боту → создаётся новый топик в группе
2. Любой модератор может ответить в топике (пересылается пользователю)
3. Модератор пишет `/claim` → тикет закреплён за ним
4. Теперь только он может отвечать (другие видят блокировку)
5. `/add @username` — добавить ещё одного модератора
6. `/unclaim` — снять клейм, все снова могут писать
7. `/close` — закрыть тикет, уведомить пользователя, архивировать топик
